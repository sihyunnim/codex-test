# 자리 배치 프로그램

14명을 4개 블록으로 배치하는 간단한 웹 페이지입니다.
- 블록 구조: 각 블록 2열 3행(총 6칸)
- 전체 인원: 14명
- 배치 규칙: 각 블록은 3명 또는 4명 배치 (총 14명 모두 배치)

## 실행 방법

브라우저에서 `index.html` 파일을 열고 **배치 생성하기** 버튼을 누르세요.

## 동작 방식

1. 14명 이름을 랜덤으로 섞어 1단계 결과를 보여줍니다.
2. 4개 블록 중 2개 블록은 4명, 2개 블록은 3명이 되도록 랜덤 분배해 총 14명을 모두 배치합니다.
3. 각 블록 내부 6칸에서도 배치 순서를 다시 랜덤으로 섞고, 남는 칸은 `빈자리`로 표시합니다.
4. 1단계/2단계는 각각 별도 팝업 창으로 열리며, 팝업 차단 시 페이지 내부 미리보기를 제공합니다.

## 현재 인원 명단

김시현, 육나영, 정애리, 변선희, 이경민, 유혜진, 공승환, 곽기은, 배병준, 서현지, 신해빈, 이건형, 하승아, 김희준
