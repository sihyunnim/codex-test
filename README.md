# 자리 배치 프로그램

14명을 4개 블록으로 배치하고, 3단계 추가업무까지 선발하는 웹 페이지입니다.
- 블록 구조
  - 1~3블록: 2열 3행
  - 4블록: 3열 2행
- 자리 배치 인원: 14명
- 추가업무 배치 인원: 15명(기존 14명 + 양만석)

## 실행 방법

브라우저에서 `index.html` 파일을 열고 **배치 생성하기** 버튼을 누르세요.

## 동작 방식

1. 자리 배치용 14명 이름을 랜덤으로 섞어 1단계 결과를 페이지에 표시합니다.
2. 2단계에서 4블록 자리를 구성하며, 블록별 배치 인원은 3명 또는 4명(총 14명)이고 블록 내부 좌석도 랜덤입니다.
3. 추가업무 3단계는 15명(기존 14명 + 양만석)을 랜덤으로 섞은 뒤 진행합니다.
4. 추가업무(아틀라시안/프린터기/얼굴인식/사물함) 선발 시 지난 회차 수행자(신해빈, 이건형, 정애리, 김충환)는 제외합니다.
5. 모든 결과는 팝업 없이 페이지 내에서 바로 확인합니다.

## 현재 인원 명단

- 자리 배치 14명: 김시현, 육나영, 정애리, 변선희, 이경민, 유혜진, 공승환, 곽기은, 배병준, 서현지, 신해빈, 이건형, 하승아, 김희준
- 추가업무 15명: 위 14명 + 양만석
